# Add Page Numbers to PDF — Free Online Tool

**Add Page Numbers to PDF.** Add page numbers to a PDF with configurable position and start number. 100% in your browser, no watermark. No sign-up, no ads, 100% client-side.

🌐 **Demo en vivo / Live demo:** [miguelacm.es/tools/pdf-page-numbers](https://miguelacm.es/tools/pdf-page-numbers)

## ✨ Features

- **🔢 Page numbers:** Add numbers to every page with a chosen start value.
- **📍 6 positions:** Top or bottom, left, center or right.
- **🔒 100% private:** PDFs are processed locally with pdf-lib.

---

## 🚀 Quick start

```bash
git clone https://github.com/m-a-c-m/PDFPageNumbers.git
cd PDFPageNumbers
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Environment variables (optional)

```env
NEXT_PUBLIC_SITE_URL=https://miguelacm.es/tools/pdf-page-numbers
NEXT_PUBLIC_EMBED_URL=https://miguelacm.es/embed/pdf-page-numbers
```
